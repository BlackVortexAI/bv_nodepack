## Replacement quality bar

- Prefer 16:9 or a tight landscape crop.
- Use English UI labels.
- Avoid open menus unless the menu itself is the subject.
- Show one concept per image.
- Ensure cables do not obscure node titles or controls.
- Use the same dark ComfyUI theme and zoom level throughout a sequence.
